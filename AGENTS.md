# AGENTS.md — Acoustic Realms (Whale Song & Birdsong AI Lab)

## Project overview

An immersive bioacoustics AI experience in two chapters:

- **Whale song recognition `/whale`**: humpback voiceprint classification
  (deep-ocean theme, cyan accents)
- **Birdsong classification `/bird`**: five songbird species + live microphone
  recognition (misty-forest theme, gold accents)

All deep learning runs locally in the browser via **TensorFlow.js** — audio data is
never uploaded anywhere.

## Tech stack

- Next.js 16 (App Router) · React 19 · TypeScript 5 (strict)
- Tailwind CSS 4 (custom design system in `globals.css`)
- @tensorflow/tfjs 4.x (browser-side CNN, dynamically imported)
- Web Audio API (OfflineAudioContext decode/resample) + hand-written radix-2 FFT
- Background: AI-generated 720p cinematic clips (`public/media/*.mp4`). The whale
  page uses `once` mode — play clip A through, hold the poster frame statically,
  then replay. The bird page crossfades two clips. Posters + CSS mist layers cover
  any video failure.

## Conventions

- All UI copy and comments are English. Species `zh` fields in
  `scripts/collect-audio.mjs` are dataset metadata only (not rendered).
- The dataset manifest `public/media/audio/dataset.json` is generated by
  `scripts/collect-audio.mjs`; regenerate with `node scripts/collect-audio.mjs`.
- Keep DSP/ML code framework-free (pure TypeScript) so it stays portable and
  testable outside React.
- `VideoBackground` supports `mode="loop"` (A/B crossfade) and `mode="once"`
  (play A → static hold → replay). The whale page uses `once`.
